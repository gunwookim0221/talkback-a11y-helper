runtime enabled ≠ canonical Full membership

checked-in runtime_config.json에는 32개 entry가 있고 기본 enabled는 targeted execution용 1개입니다. 구현은 이 값을 canonical Full의 정의로 사용하지 않고, source registry 전체를 기준으로 Full selection을 판정합니다.

정확한 계약은 scenario source와 run profile 문서를 참조합니다.
