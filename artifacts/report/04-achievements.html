보고서 04 · 현재 구현 기능

현재까지의 성과

완료된 기능을 현재 구현 기능 중심으로 정리합니다. 숫자로 된 검증 승인 결과는 실행 날짜와 범위가 확인되는 경우에만 과거 검증 근거로 표시합니다.

실행 자동화

시나리오와 Batch 기반 실행

  • 전체 검증 목록과 Full/Smoke/Custom 실행 방식
  • QA Frontend의 사전 점검, 시나리오 선택, Batch 모니터와 실행 이력
  • 시나리오 진입, 오버레이, 로컬 탭, 중지 규칙, 체크포인트와 XLSX 내보내기
탐색

실제 포커스 중심 순회

  • Traversal Identity V2 기본 운영과 강한 증거 판정
  • 스크롤, 스크롤 후 재발견, 범위를 제한한 복구와 언어·단말 보정
  • 불확실하거나 위험한 결과의 Legacy fallback과 fail-closed 처리
증거 / 판독

검토 가능한 증거

  • 화면 정보, TalkBack 발화 관찰, 실제 포커스와 증거 이벤트
  • 화면 캡처·잘라낸 화면, raw/filtered/summary/result, 결과 대조와 진단 projection
  • 제품 접근성 검토 항목과 자동화 진단의 분리
비교 / 기준선

Candidate에서 Baseline까지

  • 조건을 충족한 Full Run의 추가 Candidate 생성
  • Offline Validation과 결정적인 Comparator 보고서
  • 사람의 명시적 검토·승인 뒤 Approved Baseline 유지
현재 구현 기능과 검증 결과는 다릅니다.

위 항목은 source와 운영 계약에서 확인되는 구현 기능입니다. 최신 main에 대한 새로운 32개 물리 단말 Full Validation 승인 결과가 기록된 근거에 없으므로, 이 페이지는 전체 PASS 비율을 제시하지 않습니다.
