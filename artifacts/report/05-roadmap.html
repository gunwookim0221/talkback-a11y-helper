Report 05 · Future design

향후 개선 방향

일일이 object를 등록하는 automation에서, 화면에 도달한 뒤 현재 accessibility state를 발견하고 실제 TalkBack traversal과 reconcile하는 crawl로 진화하는 설계 방향입니다.

미래 architectural direction

State-Graph 기반 Accessibility Crawl은 현재 authoritative production traversal이 아닙니다. 현재 구현은 Scenario-driven traversal과 Traversal Identity V2를 사용하며, 아래 내용은 Audit, SMART_NEXT, Evidence, Reconciliation을 통합·확장하기 위한 후속 설계입니다.

유지보수의 중심을 이동

앱 version, resource-id, anchor, dynamic content와 object hierarchy가 바뀔 때 현재는 개별 target과 path 보정이 필요할 수 있습니다.

화면 도달 → 현재 tree 수집 → candidate 발견
→ 실제 focus/speech/evidence → MISSED/UNEXPECTED reconcile

목표는 zero maintenance가 아니라 individual object definition보다 screen entry와 exceptional policy에 maintenance를 집중하는 것입니다.

Navigation은 사라지지 않습니다

Home → Devices → plugin → detail처럼 의미 있는 화면/state로 가는 Navigation layer는 anchors, screen identity와 bounded fallback을 계속 사용할 수 있습니다.

화면 안에 도달한 뒤의 Accessibility Audit layer를 dynamic discovery/traversal 중심으로 전환하는 것이 핵심입니다.

Safe by design

발견된 object를 세 가지로 구분

읽기 / 검증 객체

text, label, informational control처럼 읽고 검증하되 generic crawler가 activate하지 않는 대상입니다.

Safe Navigation 객체

tab, More, Expand, safe submenu처럼 다른 accessibility state를 보여 줄 수 있는 대상입니다. safety policy와 state-change verification이 필요합니다.

Action / 위험 동작 객체

ON/OFF, delete, reset, save, payment, purchase, factory reset 등은 자동 activate하지 않습니다. 명시적 scenario/policy 제어 아래 둡니다.

기존 Audit과 Smart Move를 버리지 않는 확장

Auditpotential candidate 정의
Smart Traversalactual TalkBack 방문 관찰
Speech / Evidence실제 노출 기록
Reconciliationexpected ↔ actual 비교
Safe Navigation다음 state 검토

초기 Smart Move의 next-object/scroll 개념은 Accessibility Tree, focus identity, recovery와 reconciliation으로 확장되었습니다. 다만 현재 모든 move가 SMART_NEXT를 쓰는 것은 아니며 deterministic target path와 fallback을 함께 보존합니다.

No dates invented

로드맵 성숙도

현재 기반
이미 재사용 가능한 자산

Accessibility Tree/XML observation, Audit candidate/coverage, Traversal Identity, Production Traversal, SMART_NEXT-related capability, scrolling/recovery, speech/evidence, reconciliation.

다음 검토
code-level gap analysis

candidate contract, candidate identity, expected speech, actual-focus matching, MISSED/UNEXPECTED semantics, Safe Navigation classification, state fingerprint와 bounded graph 탐색.

중장기 목표
더 넓은 automatic accessibility crawl

plugin/version resilience, locale/device adaptation, evidence-driven state coverage와 충분한 검증 뒤 automatic traversal의 controlled promotion.
