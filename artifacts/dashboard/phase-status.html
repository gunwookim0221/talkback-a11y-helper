현재 구현 기능 상태

단계 번호만 나열하지 않고, 현재 실제로 사용할 수 있는 기능과 향후 설계 기능을 같은 표에서 서로 다른 상태로 구분합니다.

영역상태현재 해석
시나리오 실행구현시나리오 중심 실행과 Batch 실행 제공
QA Frontend구현사전 점검, 실행 방식, 시나리오 선택, 현재 실행과 이력 제공
Canonical Full Validation구현TAB_CONFIGS 기반 32개 전체 검증 목록; runtime enabled와 분리
실제 운영 순회기본 사용Traversal Identity V2의 강한 증거 판정과 Legacy fallback
Traversal IdentityV2 기본실행 단위 기본값; 명시적으로 끄면 Compatibility Mode
복구 / 스크롤구현범위를 제한한 복구, 재발견, 언어별 화면 보정
증거 / 결과 대조구현포커스, 발화, 화면 정보, 화면 캡처·잘라낸 화면, ledger와 결과 대조
검토구현제품 접근성 검토와 자동화 진단 분리
Candidate조건부 구현조건을 충족한 Full Run에서 결과 입력을 추가 생성
Comparator / Baseline구현오프라인 결과 비교와 사람의 명시적 승인
Audit / 커버리지진단 계층후보·커버리지·증거를 보여주는 진단 표시; 제품 판정의 운영 기준 아님
V10 ShadowShadow 전용인벤토리, 식별, 정책, 비교와 준비도 제공
Controlled Routing미구현V10 향후 범위; 실제 운영 순회를 켜지 않음
다중 단말 Baseline제한적검토된 정확 모델 정책과 제한적인 단말 계열별 커버리지
객체 자동 발견설계 검토 필요향후 로드맵; 현재 객체 자동 발견 기능으로 표시하지 않음
안전한 화면 이동설계 검토 필요향후 분류·정책; 위험 동작은 명시적으로 제어
State-Graph Crawl미구현향후 설계 방향; 현재 운영 기능 아님
향후 기능 표시 원칙

객체 자동 발견, 일반적인 안전한 화면 이동, State-Graph Crawl은 모두 계획·설계 검토·미구현으로 표시합니다. 현재 Audit과 SMART_NEXT 관련 기능이 있다는 사실을 향후 자동 탐색 기능의 구현으로 확대 해석하지 않습니다.
